# LP-ToM: Language-Primed Simulation Theory of Mind for Adaptive Head-to-Head Autonomous Racing

Code, benchmark rivals and raw results for the paper
*Language-Primed Simulation Theory of Mind for Adaptive Head-to-Head Autonomous Racing*.

Everything is pure Python on NumPy, SciPy and Matplotlib. It needs no GPU, no deep-learning
framework and no downloaded weights, and it runs on Windows, macOS and Linux.

## Contents

```
lptom/            the method, the simulator and all baselines (Python package)
scripts/          experiments, statistics, figures and verification
tests/            unit tests
benchmark/        the two reinforcement-learned rivals used in the paper (fixed, with training logs)
results/          the paper's run: raw results, logs and trained models for test seeds 301-310
reference/        frozen copies of the published tables, quoted numbers and statistics
paper/            tables, figures and quoted numbers, regenerated by the scripts
```

## Install

Python 3.11 or newer.

```bash
python -m pip install -r requirements.txt
```

On Windows write `py` instead of `python`. Run every command from this folder.

## 1. Quick check (about 5 minutes)

```bash
python scripts/quick_check.py
```

This runs the unit tests and a tiny end-to-end experiment. It then rebuilds every table,
figure and number of the paper from the stored raw results and compares them with
`reference/`. It ends with `REPRODUCED`.

## 2. Rebuild the paper's tables and figures from the stored results (minutes)

```bash
python scripts/analyze.py                    # statistics -> results/summary.json, tables -> paper/tables/
python scripts/make_misspec_figure.py        # Figure 2
python scripts/fill_results.py               # every number quoted in the text -> paper/numbers.json
python scripts/make_result_figures.py        # Figures 3-5
python scripts/make_architecture_figure.py   # Figure 1
python scripts/verify_reproduction.py # must print REPRODUCED
```

## 3. Re-run the experiments yourself (hours)

Your run goes to `results_mine/`. The paper's run in `results/` is never touched.

```bash
python scripts/verify.py --seeds 301 --parts A            # one seed, first three conditions, about 1.5 h
python scripts/verify.py --seeds 301 302 --workers 2      # two complete seeds, about 5 h
python scripts/verify.py --workers 4                      # all ten seeds, about 7-10 h on 4 cores
```

`verify.py` writes `results_mine/comparison.txt`, which lists for every agent and condition
the paper's win rate, yours, the difference and whether every race ended identically. When
all ten seeds are done it also writes your own `summary.json`, `tables/` and `figures/` into
`results_mine/`. Each worker needs about 1.5 GB of RAM. The full protocol is about 26 CPU-core hours.

On Linux x86-64 with the versions in `requirements.txt`, a re-run reproduces the stored
results race for race. Another operating system or NumPy build can round floating-point
numbers differently in the last digits. Single races may then end differently and win rates
move by a few tenths of a point. The conclusions rest on ten seeds and on effects that hold
in every seed, so they do not depend on such rounding.

## Where each part of the paper comes from

| Paper item | Produced by | Stored in |
|---|---|---|
| Raw per-race outcomes | `scripts/run_experiments.py` (via `run_all.py` or `verify.py`) | `results/seed_<S>_<A,B,C>.json` |
| Trained networks of every seed | `scripts/run_experiments.py` | `results/models_seed_<S>.pkl` |
| Training and evaluation logs | `scripts/run_experiments.py` | `results/log_seed_<S>_<A,B,C>.txt` |
| All statistics and planned tests | `scripts/analyze.py` | `results/summary.json` |
| Tables 3-7 | `scripts/analyze.py` | `paper/tables/*.tex` |
| Numbers quoted in the results section and abstract | `scripts/fill_results.py` | `paper/numbers.json` |
| Figure 1 | `scripts/make_architecture_figure.py` | `paper/figures/fig_architecture.pdf` |
| Figure 2 | `scripts/make_misspec_figure.py` | `paper/figures/fig_misspec.pdf` |
| Figures 3-5 | `scripts/make_result_figures.py` | `paper/figures/fig_belief.pdf`, `fig_switch.pdf`, `fig_regret.pdf` |
| Out-of-family RL rivals | `scripts/train_oof_rivals.py 400` | `benchmark/rl_rival_{a,b}.pkl` |

Each result file is plain JSON. In `results/seed_301_A.json`, every entry under
`results -> condition -> agent -> races` holds the outcome of every race (`1` means the
ego car won).

## Experimental protocol

- Development seeds 0, 11 and 12 fixed every design choice. The ten test seeds 301-310 were
  run once with the final configuration.
- Each seed runs in three parts so that no single job is long. Part A trains all models and
  evaluates the seen, unseen and switch conditions. Parts B and C reuse the models and
  evaluate the remaining conditions. `analyze.py` merges the parts.
- The paper's run used a Linux server with two cores of an Intel Xeon processor at 2.1 GHz,
  Python 3.13, NumPy 2.5.3, SciPy 1.18.1 and Matplotlib 3.11.2. Each run is single-threaded
  and deterministic for a given seed.

## Main source files

| File | Content |
|---|---|
| `lptom/sim.py` | vectorised two-car Frenet simulator, manoeuvres, parametric rival policy |
| `lptom/track.py` | procedurally generated tracks, racing line, reference speed |
| `lptom/opponents.py` | rival style families, seen and unseen |
| `lptom/oof.py` | out-of-family rivals, four rule-based and two PPO-trained |
| `lptom/model.py` | inference network (neural posterior estimation) and value networks |
| `lptom/language.py` | spotter radio messages and bag-of-words encoder |
| `lptom/agents.py` | Gaussian and run-length mixture beliefs, residual posterior, all agents, evaluation loop |
| `lptom/mental.py` | mental simulation of candidate manoeuvres |
| `lptom/rival.py` | learned rival model and its Bayesian last-layer basis |
| `lptom/baselines.py` | PPO racer and LIAM-style opponent model |
| `lptom/autograd.py`, `lptom/nn.py` | small reverse-mode autodiff core and network layers |

## Privileged information

Rival style parameters and simulated counterfactual outcomes are used only for training.
At test time LP-ToM observes kinematics and the radio message. It imagines the rival with the
learned rival model and its online residual, never with the simulator's rival policy. The
agents `oracleQ`, `sim-oracle` and `sim-truepolicy` read the true rival and serve only as
upper bounds.
